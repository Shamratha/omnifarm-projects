Calibration & analysis assumptions

Coordinates are normalized to the sample page content box (top-left origin). The browser chrome is excluded; overlay layers and cursor use the same .sample-page box.

No tracker calibration is performed here. Source calibration is assumed; confidence is supplied by the recording, not an accuracy measurement. Resizing preserves normalized position, not the identity of reflowed page elements. Source screen dimensions, scroll history, and device-pixel ratio are not reconstructed.
