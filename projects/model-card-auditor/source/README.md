# Prism — Model Card Auditor

Prism is a local React + Vite model-card auditor. It reviews synthetic model-card evidence, compares illustrative risk trade-offs, previews a complete review packet, and exports the same Markdown snapshot.

## Scope and provenance

Prism runs fully locally and uses synthetic, repository-provided evidence. Its results are evidence-only auditing limits: they are not assurance or certification, and Prism does not semantic-fact-check claims. Reviewers should interpret findings in context and verify source material independently.

Review packets export as Markdown. The repository's example model-card data and evidence are synthetic and intended for development and testing.

## Review routes

- `/` — existing model-card audit and dimension panels.
- `/risk-tradeoffs?model=atlas-assist` — all privacy, fairness, threat, accessibility, and claim flags. Filter by category and severity; each flag shows its rule rationale, synthetic source record paths and values, and suggested action. Compare strategies with numeric estimates and signed changes versus the card's current strategy.
- `/packet-preview?model=atlas-assist` — readable full packet generated by the same function used for download. Includes source records, scoring methodology, limitations, and optional reviewer notes.

Use the **Risk trade-offs** and **Packet preview** navigation buttons, or open the routes directly. Replace `atlas-assist` with `harbor-screen` or `lumen-caption`. Model selection stays in the current route; reload and browser back/forward retain the model specified in the URL. Unknown models or paths show a friendly error instead of silently substituting a different packet.

Comparison selection is illustrative only: it does not apply a mitigation, change the card, resolve a flag, or modify coverage. All estimates are fictional, not measurements; fairness visibility is not a fairness guarantee. The packet records all bundled strategies, not an applied strategy change.

The dashboard also includes a claim evidence inspector (defaulting to unsupported claims), with native expandable references, local source paths, unresolved IDs, and a completeness-only warning. Privacy and fairness quick actions filter findings without changing the audit. Display-only privacy-risk and fairness-visibility toggles hide or reveal dashboard estimates; they do not change findings, scores, or the packet, and a reset control restores both estimates.

Security review includes eight synthetic threat fixtures matched to the bundled threat records. Fixtures are inert narrative-only examples for manual discussion: they are never executed, live-tested, scored, or treated as evidence. The scoring-rule explanation panel documents every finding trigger, coverage unit, threshold, formula, and uncertainty limitation, including the strict >5pp accuracy-gap rule, n<30 small-sample prompt, complete-reference-only claim support, self-reported threat/accessibility statuses, and equal-weight overall coverage.

Reviewer notes are held only in memory and separately for each model. They are never put in the URL or browser storage; reload clears them. The preview renders exported Markdown with raw HTML disabled and inactive links/images, so previewing a packet does not fetch external material.

When serving `dist/` outside Vite, configure a single-page-app fallback to `index.html` for these routes. `npm run preview` provides that fallback locally.
