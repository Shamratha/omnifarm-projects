# The last signal — bundled illustrations

These four landscape illustrations are original, hand-authored procedural SVG artwork created for the dark cinematic editorial app **The last signal**.

| File | Subject | Dimensions |
| --- | --- | --- |
| `skyline.svg` | Violet and indigo dusk skyline with layered architecture and one warm signal window | 800 × 450 |
| `window.svg` | Amber building windows seen through rain and haze | 800 × 450 |
| `hands.svg` | Teal silhouette reaching toward rain-streaked glass and distant city bokeh | 800 × 450 |
| `rooftop.svg` | Sage-green rooftop with antennas, electric cloud light, and a small amber practical | 800 × 450 |

**Credits / rights:** Original procedural illustration · CC0

The artwork is self-contained: gradients, shapes, filters, and noise textures are embedded in each SVG. No remote resources, external links, or generated live models are used.
