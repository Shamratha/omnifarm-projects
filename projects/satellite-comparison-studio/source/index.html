ABOUT THIS DEMO

A local-first comparison lab.

Fieldnote uses tiny, hand-authored infrared and visible-light arrays. The canvas view is rendered in your browser, while the report is assembled from the same deterministic data. There are no network calls or external vision models.

Tip: switch to the “Archive haze” fixture to see stale imagery and a heavier cloud mask.
