# Omnifarm project publication

This repository is a clean review index for 31 completed Omnifarm sessions. Each entry contains a final project source snapshot, a derived summary, and a package index tied to the controlled remote build package. The ten entries added on 2026-10-14 are standalone local prototypes inspired by GSoC-style project ideas. They are not claims of completing or replacing upstream GSoC projects.

The public repository intentionally excludes raw conversation archives, debug logs, temporary Docker workspaces, credentials, tokens, private keys, and full server snapshots. Those remain in the controlled build environment and are referenced by package name only.

## Reading an entry

summary.json contains review-safe funnel, work, verification, replay, and static-QC metadata. package-index.json names the controlled evidence files without copying private traces into GitHub. source/ contains only the final project workspace after removal of caches, dependency trees, test-result folders, and private configuration files.

Replay levels are reported as produced by Omniconv. They are not claims that every replay is strict or fully deterministic. A none level means the package was shipped but its verifier did not award a replay level, and should be reviewed with the notes in its summary.

## Provenance

The source packages were prepared on the designated remote build server. This repository is a publication index and source snapshot, not a replacement for the controlled trace archive.
